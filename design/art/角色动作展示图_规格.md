## 0. 全局约束（适用于所有 6 个动作）

### 0.1 视角约束（继承自已审批风格图 A）

| 维度 | 规格 |
|------|------|
| 摄像机类型 | Orthographic（正交投影） |
| 视角类型 | 2D Top-Down 3/4 View（俯视 3/4 视角） |
| 摄像机倾角 | 0°（无 Y 轴旋转，Sprite 自身绘制 3/4 纵深） |
| 角色朝向 | 6 个动作全部以**侧前方（front-side profile）**呈现——身体前方面向镜头偏一侧 |
| 透视变形 | 无（正交投影） |
| 网格地面 | 角色脚下始终可见暗青灰 `#2A3B4A` 40% 透明度网格 |

### 0.2 角色基线设定（David Martinez 启发 + SBPK 色板）

**视觉灵感来源**：赛博朋克《边缘行者》大卫·马丁内斯的"年轻赛博战斗者"形象——黑色赛博夹克、赛博义体、年轻干练、敏捷体型。

**SBPK 化处理**：
- **保留**：年轻战斗者的 silhouette 与动势能量
- **替换**：用美术圣经 §2 色板替换 Cyberpunk 2077 的色彩（不用鲜艳的红色夹克、不用纯白、不用饱和蓝紫等"原版"颜色）
- **像素化**：16-bit 像素艺术呈现，禁止任何赛璐璐/写实渲染

| 部位 | 视觉元素 | 色彩引用 | 说明 |
|------|---------|---------|------|
| 头发 | 短刺发（向后方飘动感） | `#1A1A1A` 暗夜黑 | 与大卫相同的短发造型 |
| 面部 | 半面防毒面罩 + 单只发蓝光赛博眼 | 面具 `#2A2F35` 眼 `#00F0FF` | 与美术圣经 §4.1 玩家角色一致 |
| 夹克 | **黑色赛博夹克 + 警示黄斜条** | 主色 `#0A0E14` 黄条 `#FFD700` | 大卫风格的黄条纹，但用 SBKP 警示黄 |
| 夹克下摆 | 数据蓝 LED 灯带 | `#00F0FF` 100%（发光态） | 玩家势力标识 |

| 双手 | 战术手套 | `#1A1A1A` 关节 `#FFD700` | 警示黄关节扣 |

## 1. 动作 1：跑步（Run）

### 1.1 构图描述

**画面内容**：角色从画面左下方向右上方奔跑，**身体前倾约 25-30°**，一臂前摆、一臂后摆，前腿迈出、后腿蹬地，呈现强烈运动感。脚下扬起少量灰尘粒子（暖灯橙/锈血红半透明）。

**视角**：侧前方 3/4 视角。**关键特征**：角色脸部和右臂（赛博义肢）同时可见——身体的 3/4 朝向镜头。

**动感元素**：
- 头发向后方飘动
- 夹克下摆被风掀起
- 脚下地面网格有 1-2 个亮起的"脚印光斑"（数据蓝 #00F0FF 30% 透明度）暗示移动轨迹
- 背景有 3-4 条横向"速度线"（1px 暗灰 #3A3F4A）增强运动感
- 可选 1-2 个微弱的像素拖影帧（数据蓝 20% 透明）

### 1.2 角色姿态细节

| 部位 | 姿态 |
|------|------|
| 头部 | 略微下视前方，护目镜反射数据蓝光 |
| 躯干 | 前倾 25-30°，左肩略低于右肩（重心在前） |
| 右臂（义肢） | 前后摆动——前摆时肘部弯曲约 90° |
| 左臂 | 后摆，肘部伸直 |
| 前腿（右腿） | 膝盖抬起，股四头肌发力，大腿接近水平 |
| 后腿（左腿） | 蹬地伸直，脚跟离地 |
| 双手 | 自然握拳，义肢手指关节有蓝光闪动 |

### 1.3 色彩引用

| 用途 | 颜色 | Hex |
|------|------|-----|
| 夹克主色 | 暗夜黑 | `#0A0E14` |
| 夹克黄条 | 警示黄 | `#FFD700` |
| LED 灯带 | 数据蓝（亮） | `#00F0FF` |
| 义肢金属 | 金属灰 | `#4A5055` |
| 速度线 | 混凝土灰 | `#3A3F4A` |
| 地面光斑 | 数据蓝 | `#00F0FF` 30% |
| 灰尘粒子 | 暖灯橙 + 锈血红 | `#FF8C00` 50% + `#5C1A1A` 30% |
| 背景暗 | 暗夜黑 | `#0A0E14` |

### 1.4 像素尺寸

- 角色整体：约 32×48 px（站立框），跑步时**高度压缩到约 36-40px**（前倾压缩）
- 速度线：每个网格 1px 高
- 脚印光斑：每个 8×8 px

## 2. 动作 2：开枪（Shoot）

### 2.1 构图描述

**画面内容**：角色站立侧前方 3/4 视角，**双臂前伸持枪射击**。枪口发出短促的**火焰与烟雾 VFX**（暖灯橙 `#FF8C00` + 骨白 `#D4C5A0`）。身体因后坐力微微后仰，双脚前后分开保持稳定。

**视角**：侧前方 3/4 视角。**关键特征**：武器和角色 3/4 朝向镜头，枪口火焰清晰可见。

**武器选择**：赛博朋克风**单手持手枪**（推荐）或短冲锋枪。手枪形制参考 Cyberpunk 2077 的强化手枪——金属质感的全息瞄准镜 + 蓝色能量指示灯。

**动感元素**：
- 枪口火焰：2-3 帧的椭圆形火焰（暖灯橙 → 骨白渐变）
- 烟雾：1-2 缕浅灰白烟
- 弹壳抛出：1 颗黄铜弹壳（警示黄 `#FFD700` 80% 饱和度）在空中翻转
- 后坐力效果：角色肩膀微后仰，护目镜上反射火光
- 枪口前方有微弱的**激光瞄准线**（赛博紫 `#B026FF` 30% 透明度的虚线，3-4 段）

### 2.2 角色姿态细节

| 部位 | 姿态 |
|------|------|
| 头部 | 微微下视，护目镜贴近瞄准线 |
| 躯干 | 站立稳定，重心略后移（后坐力） |
| 右臂（义肢） | 前伸持枪，肘部微屈，**义肢关节因发力发出更亮数据蓝** |
| 左臂 | 辅助托住右手（双手持枪），前臂前伸 |
| 双手 | 双手握枪，义肢手指扣扳机 |
| 双腿 | **前后分开站立**（右前左后，标准射击站姿） |
| 武器 | 单手/双手手枪，赛博强化型，金属 `#4A5055` + 指示灯 `#00F0FF` |

### 2.3 色彩引用

| 用途 | 颜色 | Hex |
|------|------|-----|

| 义肢 | 金属 + 数据蓝 | `#4A5055` + `#00F0FF` |

## 3. 动作 3：翻滚（Dodge Roll）

### 3.1 构图描述

**画面内容**：角色在地面**侧向翻滚**，身体**弓起蜷缩成球形**，双手护头，呈现明显的滚动姿态。身体中段最低点接近地面，头发飞扬在空中。可叠加 2-3 个**连续残影帧**（前 1-2 帧动作）增强翻滚动势。

**视角**：侧前方 3/4 视角。**关键特征**：角色呈现"侧翻"姿态——身体横向而非竖直。

**动感元素**：
- 翻滚方向：从画面左下向右上方翻滚，或反过来
- 残影帧：1-2 帧前动作的拖影（数据蓝 20-30% 透明度）
- 地面扬尘：翻滚接触点扬起环形灰尘（暖灯橙 + 锈血红）
- 头发飞扬：短发因翻滚飘起呈放射状
- 夹克下摆 LED 灯带在翻滚中留下**弧形光带残影**（数据蓝 30% 透明度）
- 地面网格在翻滚起点有一个"刮痕"（暗红 `#5C1A1A` 30% 透明度）

### 3.2 角色姿态细节

| 部位 | 姿态 |
|------|------|
| 头部 | 低头缩进肩部，双手护住头顶 |
| 躯干 | **弓起**——胸朝下，背部拱起（蜷缩） |
| 双臂 | 弯曲护在头两侧，肘部朝外 |
| 双腿 | 弯曲收于身下，膝盖朝外 |
| 整体形态 | 类似球形/弓形，最低点接近地面 |

### 3.3 色彩引用

| 用途 | 颜色 | Hex |
|------|------|-----|
| 夹克 | 暗夜黑 + 警示黄条 | `#0A0E14` + `#FFD700` |
| 义肢 | 金属 + 数据蓝 | `#4A5055` + `#00F0FF` |
| 扬尘 | 暖灯橙 + 锈血红 | `#FF8C00` 50% + `#5C1A1A` 30% |
| 残影帧 | 数据蓝 | `#00F0FF` 20-30% |
| 弧形光带 | 数据蓝 | `#00F0FF` 30% |
| 地面刮痕 | 锈血红 | `#5C1A1A` 30% |
| 背景 | 暗夜黑 | `#0A0E14` |

### 3.4 像素尺寸

- 角色整体：约 **40×32 px**（横向翻滚时宽大于高）
- 残影帧：每帧约 32×40 px，叠加在主帧背后
- 扬尘：约 16×8 px 环形扩散

### 8.3 验收标准

每张图/每格交付前须通过以下验收：

- [ ] **视角约束**：俯视 3/4 视角正确，角色侧前方朝向
- [ ] **角色一致性**：6 个动作的角色造型（夹克、义肢、面部、装备）完全一致
- [ ] **像素风格**：明显像素艺术特征，无 3D 渲染痕迹
- [ ] **色彩合规**：使用美术圣经 §2 的 Hex 颜色，不出现色板外颜色
- [ ] **负面排除**：未出现农场/温暖/牧歌/3D/抗锯齿等关键词相关视觉元素
- [ ] **动作姿态准确**：每个动作的 pose 与本规格 §1-6 中的姿态细节完全匹配
- [ ] **VFX 必含**：每个动作的必含 VFX 全部出现且无遗漏
- [ ] **大卫风格融合**：保留大卫的"年轻赛博战斗者" silhouette，但配色和细节按美术圣经执行
- [ ] **赛博紫无滥用**：血光粉 #FF003C 严格限用于受击和死亡场景，赛博紫 #B026FF 限用于刀光和品牌强调

### 8.4 与现有美术圣经的协调

- **色板引用**：所有颜色均来自美术圣经 §2，**不引入新颜色**
- **视角规范**：与美术圣经 §3.1 一致
- **角色比例**：与美术圣经 §3.2 一致（玩家 32×48）
- **角色特征**：在美术圣经 §4.1 基础上加入大卫启发元素（警示黄斜条夹克）

## 9. 待审批与风险事项

### 待用户审批项

1. **布局方案选择**：Option A（6 宫格拼图，推荐）vs Option B（单帧动势特写）——是否采纳推荐？
2. **大卫视觉元素融合度**：当前方案保留大卫的"警示黄斜条夹克 + 年轻 silhouette"，是否需要更多大卫元素（如发型精确还原、武器风格）？或更少（仅 silhouette 启发）？
3. **武器选择**：当前方案——开枪用赛博手枪、挥砍用赛博武士刀。是否需要调整武器类型（如全部用枪、或全部用近战）？
4. **6 动作是否完整**：跑步/开枪/翻滚/受击/挥砍/死亡——是否需要增减动作（如加"建造"、"使用工具"、"拾取物品"等）？
5. **AI 生图工具**：是使用 Midjourney / Stable Diffusion / DALL-E 哪种？本规格提示词已优化为通用版本。

### 风险事项

1. **AI 生图的角色一致性**：6 个动作的角色需保持完全一致的造型（夹克颜色、义肢位置、面部特征）。AI 生图对此保证较弱——建议先生成 1-2 个最关键动作（跑步、挥砍）验证造型，再批量生成其他 4 个。
2. **AI 生图的角度一致性**：每个动作都需"侧前方 3/4 视角 + 角色 3/4 朝向镜头"——AI 生图对精确角度控制较弱，可能需要：
   - 每个动作生成 4-8 张候选
   - 美术总监挑选最符合规格的
   - 人工调整不一致处
3. **死亡动作的"熄灭"语义**：AI 工具可能不会自动熄灭所有霓虹部件，需在提示词中**反复强调**（如"ALL NEON/LED EXTINGUISHED"），并由美术师后期检查确认。
4. **选项 A 的拼图对称性**：AI 一次生成完整 6 宫格难度大，可能需要先生成 6 个单图，再用图像编辑工具（如 Photoshop/Pixelmator）拼接为 6 宫格。
5. **与已有风格图 A 的角色造型差异**：如果风格图 A 的玩家角色已固定造型，本规格的"大卫启发夹克"需与之一致——需美术总监确认两个文档的角色描述是否冲突。

### 与其他团队的协调点

- **文策渊（数值/玩法）**：
  - 6 动作的伤害/帧数需要与战斗系统的伤害判定时间窗口对齐
  - "死亡"动作的视觉时长需要与死亡动画/复活机制对齐
- **程基岩（程序）**：
  - 提示词中提到的"残影帧"、"弧形光带残影"等需要 Shader 或粒子系统支持
  - "死亡暗角"叠加效果需要后处理 Pass
  - AI 生成的"速度线"等 VFX 在实际游戏中是否使用 Sprite 帧动画还是粒子系统
- **阮和鸣（音频）**：
  - 每个动作需要配对的音效（脚步声、枪声、刀声、受伤声、死亡声）
  - 受击和死亡的音效时长需要与 VFX 同步
