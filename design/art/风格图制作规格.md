> **视角参考**：用户提供的"2D 俯视 3/4 视角 + 网格化布局"参考图（**仅参考视角，不参考其美术风格**）

## 0. 全局约束（适用于所有 3 套图）

### 0.1 视角约束（最高优先级）

**必须严格遵守以下视角规格，不允许任何偏离：**

| 维度 | 规格 |
|------|------|
| 摄像机类型 | Orthographic（正交投影） |
| 视角类型 | 2D Top-Down 3/4 View（俯视 3/4 视角） |
| 摄像机倾角 | 0°（无 Y 轴旋转，Sprite 自身绘制 3/4 纵深） |
| 角色朝向 | 角色以**正侧面 / 侧前方（front-side profile）**站立，面朝下方或斜下方 |
| 地面网格 | **网格清晰可见**，作为画面的主要水平参照 |
| 透视变形 | **无**（正交投影，无透视） |
| 纵深表达 | 通过 Sprite 自身的伪 3/4 视角绘制（垂直面 1/2 缩进） |

**视角参考描述**：
> 想象你在看一张俯视 3/4 视角的农场游戏截图——格子田地、人物侧前方站立——但所有内容都换成赛博朋克废墟、霓虹灯、网格建造区、玩家和丧尸。

### 0.2 美术语言约束

| 维度 | 规格 |
|------|------|
| 艺术风格 | 16-bit / 32-bit Pixel Art（像素艺术） |
| 参考对标 | Hyper Light Drifter（末日氛围）/ Stardew Valley（俯视 3/4 视角）/ Dead Cells（战斗流畅度） |
| 像素精度 | 视觉上呈现像素感，可使用现代 AI 工具的"像素化"风格 |
| 配色基调 | **霓虹冷色 vs 废墟暖暗**——饱和度对比强烈，不允许出现参考图的明亮温暖基调 |
| 整体氛围 | 压抑、危险、迷人——赛博朋克 + 末日生存 |

### 0.3 关键词正面清单（必须出现）

```
pixel art, 16-bit, 2D top-down 3/4 view, orthographic, 
cyberpunk, post-apocalyptic, neon, ruins, 
dark atmosphere, dystopian, 
grid layout, tile-based, 
cyber ruins, 
character front-side view, isometric tilt
```

### 0.4 关键词负面清单（必须排除）

**绝对禁止出现的关键词**（参考图的农场风）：

```
❌ pastoral, ❌ farm, ❌ wheat, ❌ crops, ❌ harvest,
❌ green fields, ❌ grass field, ❌ meadow, ❌ countryside,
❌ warm sunlight, ❌ cheerful, ❌ cozy, ❌ warm green,
❌ farming simulator, ❌ storybook, ❌ cottage core,
❌ sunlit, ❌ idyllic, ❌ peaceful village,
❌ bright daylight (白天图允许，但不允许"明亮温暖"),
❌ blue sky (除非作为背景远景且已损坏 / 被污染)
```

## 1. 风格图 A：像素概念场景（Pixel Concept Scene）

### 1.1 用途

- 用于文档头图、立项汇报、Steam 商店页面主视觉（备选）
- 确立游戏的"浮空赛博城 vs 下方废墟"宏观世界观
- 验证俯视 3/4 视角 + 像素 + 赛博废墟的整体可读性

### 1.2 构图描述

**整体构图**（横向矩形，16:9 比例，建议 1920×1080）：

```
┌──────────────────────────────────────────────────────┐
│  [天  空  层]                                          │
│   ╔═══════════════════════════════════════╗          │
│   ║   浮空赛博之城（霓虹密集、悬浮倒影）    ║          │
│   ║   ████全息广告牌 / 飞行汽车 / 高塔      ║          │
│   ╚═══════════════════════════════════════╝          │
│              ║║ 能量光柱向下连接 ║║                   │
│ ─────────── 地平线 / 雾霾分界线 ──────────            │
│  [废 墟 层 - 游戏区]                                  │
│   ▓▓▓ ▓▓▓ ▓▓▓ ▓▓▓     网格建造区                       │
│   ▓██▓ ▓██▓ ▓██▓ ▓██▓  ┌─┐  玩家角色                   │
│   ▓██▓ ▓██▓ ▓██▓ ▓██▓  └─┘  (侧面站立)                │
│   ▓▓▓ ▓▓▓ ▓▓▓ ▓▓▓      👾 丧尸（远处）                 │
│   破碎混凝土 / 锈蚀金属 / 杂草                          │
└──────────────────────────────────────────────────────┘
```

**画面分区**（从上到下）：
- **天空层（画面 0-30% 高度）**：浮空赛博之城，霓虹密集，悬浮在破碎云层之上
- **过渡带（画面 30-40%）**：能量光柱 / 雾霾分界线，连接天地
- **废墟层（画面 40-100%）**：游戏区域，可见网格建造区、玩家角色、远处丧尸

**视角关键点**：
- 摄像机斜向下俯视（3/4 角），可看到建筑物的"顶面"和"正面"两部分
- 玩家角色以**侧前方朝向**站立在网格中（脸部略转向镜头）
- 网格为正方形，在地面上清晰可见（透视感弱，接近正交）

## 4. 通用制作规范

### 4.1 输出格式

| 维度 | 规格 |
|------|------|
| 文件格式 | PNG-32（RGBA，含 Alpha 通道） |
| 输出尺寸 | 1920×1080（概念图 B 可选 1600×1600 方形，对比图 C 2560×1080 横向） |
| 颜色空间 | sRGB |
| 位深度 | 8-bit per channel |
| 透明背景 | 否（需要完整场景背景） |
| 压缩 | 无（保留完整像素精度） |

### 4.2 文件命名

```
[项目]_[类型]_[名称]_[变体]_v[版本].png

示例：
sbpk_concept_scene_main_v1.png
sbpk_palette_character_lineup_v1.png
sbpk_daynight_comparison_v1.png
```

### 4.3 验收标准

每张图在交付前须通过以下验收：

- [ ] **视角约束**：俯视 3/4 视角正确，角色侧前方朝向，网格清晰
- [ ] **像素风格**：明显像素艺术特征，无 3D 渲染痕迹
- [ ] **色彩合规**：使用美术圣经 §2 的 Hex 颜色，不出现色板外颜色
- [ ] **负面排除**：未出现农场/温暖/牧歌等关键词相关视觉元素
- [ ] **元素完整**：必含元素清单（C1-C13 / B1-B13 / A1-A13）全部出现
- [ ] **色板比例**：60-30-10 法则基本符合（±10% 浮动）
- [ ] **可读性**：角色、丧尸、防御塔在 32×32 缩略图下仍可识别
- [ ] **氛围传达**：单看图片能感受到"霓虹 vs 废墟"的张力

### 4.4 修改迭代流程

1. 初版生成后提交美术总监评审
2. 评审不通过项标注（如"视角不对"、"色彩偏移"、"元素缺失"）
3. 修改后提交二版，最多三轮迭代
4. 三轮后仍未通过则重新发起任务

### 4.5 与现有美术圣经的协调

- **色板引用**：所有颜色均来自美术圣经 §2.1-2.4，**不引入新颜色**
- **视角规范**：与美术圣经 §3.1 一致

### 风险事项

1. **AI 生图的视角一致性**：纯文字提示词难以保证 100% 精确的俯视 3/4 视角，建议至少生成 4-8 张候选，由美术总监挑选后人工调整。
2. **像素风格保真度**：现代 AI 生图工具默认输出非像素风格，可能需要：(a) 使用 Stable Diffusion + 像素艺术 LoRA，(b) 生成后用 Pixel Art 滤镜处理，(c) 由像素美术师根据 AI 草图重绘。
3. **角色比例准确性**：AI 生图难以保证精确的 32×48 像素比例，需要美术师后期调整或重绘。
4. **风格图 C 的对称性**：并排两图需要建筑布局完全一致——AI 生图很难保证这点，建议先生成一张昼夜图，再通过色温/光照滤镜衍生另一张。
