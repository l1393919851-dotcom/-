# SBPK 项目框架总览

本文档说明本项目中**全部自研框架**包含哪些功能、各自负责什么、以及如何调用。  
代码位于 `Assets/Scripts/` 下，分为两大层：

| 层级 | 路径 | 定位 |
|------|------|------|
| **Base** | `Assets/Scripts/Base/` | UI + 资源加载基础层，与业务解耦 |
| **FunctionalFramework** | `Assets/Scripts/Base/FunctionalFramework/` | 场景、配置、音效、状态机、行为树、ECS 等功能扩展层 |

两层可独立使用，推荐组合使用：业务只通过各模块的 `Instance` 入口访问，不直接操作底层实现。

---

## 一、整体架构关系

```
┌─────────────────────────────────────────────────────────────┐
│                      游戏业务层（你的代码）                    │
│   面板、角色、关卡、战斗逻辑……                                 │
└──────────────────────────┬──────────────────────────────────┘
                           │ 调用
┌──────────────────────────▼──────────────────────────────────┐
│              FunctionalFramework（功能扩展）                  │
│  场景 │ 配置表 │ 音效 │ 状态机 │ 行为树 │ ECS                    │
└──────────────────────────┬──────────────────────────────────┘
                           │ 依赖
┌──────────────────────────▼──────────────────────────────────┐
│                    Base（UI + 资源）                           │
│  ResourceManager │ UIManager │ 事件 │ 控件 │ 本地化 …          │
└─────────────────────────────────────────────────────────────┘
```

**推荐启动顺序（示例）：**

1. 加载配置 → `ConfigManager.Instance.LoadAll()`
2. 初始化音效 → `SoundManager.Instance`（首次访问自动创建）
3. 打开首个 UI → `UIManager.Instance.OpenAsync<MainPanel>()`
4. 按需切换场景 → `SceneFlowManager.Instance.LoadSceneAsync(...)`

示例脚本：`Base/Examples/ExampleBootstrap.cs`、`FunctionalFramework/Examples/ExampleFunctionalBootstrap.cs`

## 二、Base 框架（UI + 资源）

详细 API 见同目录 `README.md`。

### 2.1 Common — 通用基础

| 内容 | 作用 | 怎么用 |
|------|------|--------|
| `Singleton<T>` | 纯 C# 单例（无 MonoBehaviour） | `class X : Singleton<X>` → `X.Instance` |
| `MonoSingleton<T>` | 带生命周期的单例，挂到 `[MonoSingletons]` 下 | `class X : MonoSingleton<X>` → `X.Instance` |
| `TransformExtensions` | RectTransform 锚点、居中等扩展 | `rect.SetStretch()` 等 |

**干什么用：** 所有管理器的基类，保证全局唯一入口。

---

### 2.2 ResourceFramework — 资源加载

| 入口 | 作用 |
|------|------|
| `ResourceManager.Instance` | 资源加载、释放、对象池总入口 |

**干什么用：** 统一管理预制体、图集、音频等资源；引用计数 + 延迟卸载，避免重复加载和内存泄漏。

**常用调用：**

```csharp
// 同步加载
var prefab = ResourceManager.Instance.Load<GameObject>("UI/MainPanel");

// 异步加载（回调）
ResourceManager.Instance.LoadAsync<Sprite>("Icons/Hero", sprite => { /* 使用 */ });

// 协程等待
yield return ResourceManager.Instance.LoadAsync<GameObject>("Effects/Boom");

// GameObject 对象池
var go = ResourceManager.Instance.Spawn("Prefabs/Bullet", parent);
ResourceManager.Instance.Despawn("Prefabs/Bullet", go);

// 释放引用（引用为 0 后延迟卸载）
ResourceManager.Instance.Release("UI/MainPanel");

// 切场景清空
ResourceManager.Instance.ReleaseAll();
```

**切换 Addressables：** 在 Player Settings 添加宏 `BASE_ADDRESSABLES`，启动时：

```csharp
ResourceManager.Instance.SetLoader(new AddressablesLoader());
```

### 2.3 UIFramework — UI 系统

| 入口 / 类 | 作用 |
|-----------|------|
| `UIManager.Instance` | 打开/关闭面板、栈、缓存、焦点 |
| `UIBase` | 所有面板基类，统一生命周期 |
| `[UI(...)]` | 声明预制体路径、层级、是否缓存 |
| `EventCenter.Instance` | 全局字符串事件总线 |
| `BindableProperty<T>` | 数据变化自动通知 UI |
| `ToastManager` / `DialogManager` | 飘字、确认框 |
| `RedDotManager` | 树形红点 |
| `LoopScrollView` | 循环列表（大量 item 省性能） |
| `LocalizationManager` | 多语言 |
| `GuideManager` | 新手引导镂空 |
| `InputBlocker` | 全屏挡点击（加载中） |
| `SafeAreaAdapter` | 刘海屏安全区 |
| `UIDebugger` | 运行时 F1 调试已开 UI |

**干什么用：** 所有界面经 `UIManager` 打开；层级、返回栈、隐藏池、动画一条龙。

**定义并打开面板：**

```csharp
[UI("UI/ShopPanel", UILayer.Popup, fullScreen: false, cacheable: true)]
public class ShopPanel : UIBase
{
    protected override void OnInit()    { /* 绑定按钮、订阅事件 */ }
    protected override void OnOpen(object args) { /* 刷新数据 */ }
    protected override void OnClose()   { /* 清理 */ }
}

// 打开 / 关闭
UIManager.Instance.Open<ShopPanel>(args: shopId, pushStack: true);
UIManager.Instance.Close<ShopPanel>();
UIManager.Instance.CloseTop();  // 等同返回键
```

**生命周期顺序：** `OnInit`（一次）→ `OnOpen` → `OnShow` → … → `OnHide` → `OnClose`；被盖住时 `OnBlur`，重新到顶层 `OnFocus`。

**UILayer 层级：** `Background` / `Normal` / `Popup` / `Top` / `System`（数字越大越靠前）。

**事件与绑定：**

```csharp
EventCenter.Instance.Subscribe<int>("OnGoldChange", v => RefreshGold(v));
EventCenter.Instance.Publish("OnGoldChange", 100);

public BindableProperty<int> Gold = new(0);
Gold.OnValueChanged += (_, v) => txtGold.text = v.ToString();
```

**通用控件：**

```csharp
ToastManager.Instance.Show("保存成功");
DialogManager.Instance.Show("提示", "确定退出？", onConfirm: Application.Quit);
RedDotManager.Instance.SetCount("Mail/Reward", 3);
```

**Editor 工具：** 菜单 `Tools → Base → UI Bindings Generator`，按 `_btn_xxx` 命名规则生成 partial 绑定代码。

**可选宏：** `BASE_TMP_SUPPORT`（TMP 版 Toast/Dialog/本地化）、`BASE_DOTWEEN_SUPPORT`（DOTween 动画）。

## 三、FunctionalFramework（功能扩展）

详细 API 见 `Assets/Scripts/Base/FunctionalFramework/README.md`。

### 3.1 SceneManage — 场景管理

| 入口 | 作用 |
|------|------|
| `SceneFlowManager.Instance` | 加载/卸载场景、流程跳转、进度回调 |

**干什么用：** 封装 `SceneManager` 异步加载；单场景切换时自动 `ResourceManager.ReleaseAll()`。

```csharp
// 异步加载
SceneFlowManager.Instance.LoadSceneAsync("Main", SceneLoadMode.Single,
    onProgress: p => { /* 更新进度条 */ },
    onComplete: () => { /* 进入主场景 */ });

// 叠加场景（如战斗 UI 场景）
SceneFlowManager.Instance.LoadSceneAsync("BattleUI", SceneLoadMode.Additive);

// 顺序流程：启动 → 大厅 → 战斗
SceneFlowManager.Instance.RunFlow(new[]
{
    new SceneFlowStep("Boot"),
    new SceneFlowStep("Lobby"),
    new SceneFlowStep("Battle"),
});
```

---

### 3.2 ConfigTable — 配置表

| 入口 | 作用 |
|------|------|
| `ConfigManager.Instance` | 加载 JSON/CSV，按 Id 查询 |
| `ConfigTable<T>` | 单表容器 |
| `[Config(path, format)]` | 标记表路径与格式 |
| `IConfigRow` | 配置行必须有 `Id` |

**干什么用：** 英雄、关卡、道具等数值表与代码分离；支持 `Resources` 或 `ResourceManager` 读 TextAsset。

**定义表：**

```csharp
[Config("Config/Hero", ConfigFormat.Json)]
public class HeroConfig : IConfigRow
{
    public int Id;
    public string Name;
    public int Hp;
    int IConfigRow.Id => Id;
}
```

**JSON 放 `Resources/Config/Hero.json`：**

```json
{ "items": [ { "Id": 1, "Name": "战士", "Hp": 120 } ] }
```

**调用：**

```csharp
ConfigManager.Instance.LoadAll();  // 扫描所有带 [Config] 的类
var hero = ConfigManager.Instance.GetTable<HeroConfig>().Get(1);
```

### 3.3 SoundManage — 音效管理

| 入口 | 作用 |
|------|------|
| `SoundManager.Instance` | BGM / SFX / Voice 分通道播放 |

**干什么用：** 统一播背景音乐、音效、语音；SFX 用对象池支持多路同时播放。

```csharp
SoundManager.Instance.PlayBGM("Audio/BGM_Main");
SoundManager.Instance.PlaySFX("Audio/SFX_Click");
SoundManager.Instance.PlayVoice("Audio/Voice_001");
SoundManager.Instance.SetVolume(SoundChannel.BGM, 0.5f);
SoundManager.Instance.Muted = true;
```

音频路径优先走 `ResourceManager`，否则 `Resources.Load`。

### 3.4 StateMachine — 有限状态机

| 入口 | 作用 |
|------|------|
| `Fsm<TContext>` | 注册状态、条件转换、驱动更新 |
| `IState<TContext>` | 单状态：OnEnter / OnUpdate / OnExit |
| `FsmRunner<TContext>` | 挂场景物体上自动每帧 Update |

**干什么用：** 玩家、怪物、UI 流程等「多状态切换」逻辑（待机、移动、攻击……）。

```csharp
var fsm = new Fsm<PlayerContext>();
fsm.AddState(new IdleState());
fsm.AddState(new RunState());
fsm.AddTransition<IdleState, RunState>(ctx => ctx.IsMoving);
fsm.AddTransition<RunState, IdleState>(ctx => !ctx.IsMoving);
fsm.Start<IdleState>(context);
fsm.Update(context, Time.deltaTime);  // 每帧
fsm.ChangeState<AttackState>(context); // 强制切换
```

示例：`FunctionalFramework/Examples/ExamplePlayerFsm.cs`

### 3.5 BehaviorTree — 行为树

| 入口 | 作用 |
|------|------|
| `BehaviorTreeRunner` | 挂 AI 物体，子类实现 `BuildTree()` |
| `BTContext` | 黑板 + Agent 引用 |
| 节点 | `SequenceNode` `SelectorNode` `ParallelNode` `ActionNode` `ConditionNode` `WaitNode` 等 |

**干什么用：** 怪物 AI、NPC 决策（巡逻 → 发现玩家 → 追击 → 攻击）。

**节点结果：** `Success` / `Failure` / `Running`（下帧继续）。

```csharp
// Selector：任一子节点成功即成功
// Sequence：全部成功才成功
var root = new SelectorNode();
var chase = new SequenceNode();
chase.AddChild(new ConditionNode(ctx => HasTarget(ctx)));
chase.AddChild(new ActionNode(ctx => { Chase(); return BTStatus.Running; }));
root.AddChild(chase);
root.AddChild(new ActionNode(ctx => Patrol()));
```

示例：`FunctionalFramework/Examples/ExampleMonsterAI.cs`

### 3.6 ECS — 实体组件系统

| 入口 | 作用 |
|------|------|
| `World` | 创建实体、挂组件、注册系统、每帧 Update |
| `Entity` | 实体 Id（轻量句柄） |
| `IComponent` | 组件必须为 struct |
| `ComponentStore<T>` | 某类型组件的稠密存储 |
| `ISystem` / `SystemBase` | 每帧逻辑（移动、战斗等） |
| `ECSWorldRunner` | 场景驱动 World |
| `ECSViewRegistry` | ECS 数据 ↔ GameObject 表现桥接 |

**干什么用：** 大量怪物、子弹等实体用数据驱动，逻辑与 GameObject 解耦；可选 Burst 并行加速。

```csharp
var world = new World();
var e = world.CreateEntity();
world.AddComponent(e, new PositionComponent { Value = pos });
world.AddComponent(e, new VelocityComponent { Value = Vector3.forward });
world.AddSystem(new MovementSystem(viewRegistry));
world.Update(Time.deltaTime);
```

**Burst 大量怪物（已配置包，开箱即用）：**

| 包 | 版本 | 状态 |
|----|------|------|
| `com.unity.burst` | 1.8.18 | 已写入 manifest.json |
| `com.unity.collections` | 2.1.4 | 已写入 manifest.json |
| `com.unity.mathematics` | 1.2.6 | 已写入 manifest.json |

1. **重新打开 Unity**，等待 Package Manager 下载完成（首次必须）
2. 菜单 **Tools → Functional → 检查 Burst 安装状态** 确认 `UNITY_BURST` 已定义
3. 场景挂 `ECSWorldRunner`（勾选 **Use Burst When Available**）+ `ExampleMonsterSpawner`
4. 运行后 Console 出现 `[ECSWorldRunner] Burst 已启用` 即表示 Burst 路径生效

> 无需手动添加 `FUNCTIONAL_BURST` 宏；安装 Burst 包后 Unity 自动定义 `UNITY_BURST`。

```csharp
BurstSupport.LogStatus(); // 启动时打印 Burst 是否可用
```

示例：`Base/FunctionalFramework/Examples/ExampleMonsterSpawner.cs`

## 七、新功能开发建议

1. **UI 面板**：继承 `UIBase`，加 `[UI]`，只用 `UIManager` 开关，在 `OnDestroyUI` 里反注册事件。  
2. **资源**：统一路径字符串，通过 `ResourceManager` 加载，不用完调用 `Release`。  
3. **数值**：配置行实现 `IConfigRow`，表数据放 `Resources/Config/`。  
4. **AI**：简单用状态机，复杂用行为树；同屏实体极多再考虑 ECS。  
5. **启动**：单独 `Bootstrap` 脚本里依次初始化配置、音效、首个 UI，避免散落在各处 `Awake`。
